# 🃏 Лаунчер Куколдини (Kukoldini Launcher)

Десктопный игровой хаб на базе **PyQt6**, стилизованный под формат компактных аркадных игр с единым профилем игрока, сохранением матчевой статистики в **SQLite** и сквозным логированием сессий.

## 🎯 Обзор проекта

Проект представляет собой легковесный настольный клиент со встроенными настольными играми против виртуального дилера/оппонента (Отек Куколдини). 

### Ключевые возможности:
* **Единый профиль:** вход по никнейму игрока перед стартом игровой сессии.
* **Кастомный темный UI:** единая панель навигации по вкладкам, модальные окна ставок и диалоги реванша.
* **База данных SQLite:** учет побед, поражений и персональных результатов каждого зарегистрированного игрока.
* **Централизованное логирование:** фиксация переключения экранов, транзакций ставок, ходов и системных событий в текстовый лог.

## 🎮 Игровые модули

### 1. БлекДжек Куколдини
Облегченная версия карточной классики против Куколдини:
* Модальный ввод ставок и динамический банк.
* Подсчет значений карт на руках у игрока и дилера.
* Автоматическая валидация перебора, банкротства и фиксация победы/поражения с предложением реванша.

### 2. Пешки Куколдини (Шахматы)
Классическое шахматное противостояние на 64-клеточной доске:
* Режим на двоих (Игрок против Куколдини).
* Подсветка допустимых клеток для хода и выбранной фигуры.
* Индикация текущего хода («Сейчас ходят: Белые / Черные»), фиксация шаха и мата с модальным подтверждением завершения партии.

### 3. Статистика игрока
Табличный интерфейс (`QTableWidget`), выводящий актуальную сводку из реляционной базы данных:
* Имя игрока.
* Количество побед игрока.
* Количество побед Куколдини.

## 🛠 Архитектура и стек

* **Язык разработки:** Python 3.10+
* **GUI Framework:** PyQt6 (`QMainWindow`, `QTableWidget`, `QInputDialog`, `QMessageBox`, кастомная компоновка `QGridLayout` / `QVBoxLayout`)
* **База данных:** SQLite 3 (`sqlite3`)
* **Системные модули:** `logging` (потоковый вывод и запись в файл), `os`, `sys`

## 🚀 Установка и запуск

1. **Клонируйте репозиторий или скачайте архив:**
```bash
git clone [https://github.com/your-username/kukoldini-launcher.git](https://github.com/your-username/kukoldini-launcher.git)
cd kukoldini-launcher

```


2. **Создайте и активируйте виртуальное окружение:**
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

```


3. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


4. **Запустите лаунчер:**
```bash
python launcher_kukoldini.py

```

## 📊 Логирование и база данных

### База данных (SQLite)

Таблица `players_stats` хранит историю противостояний:

```sql
CREATE TABLE IF NOT EXISTS players_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    player_name TEXT UNIQUE NOT NULL,
    player_wins INTEGER DEFAULT 0,
    kukoldini_wins INTEGER DEFAULT 0
);

```
